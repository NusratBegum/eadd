EADD: drift detection demo

Paper (IEEE) Source

Enhanced Adversarial Drift Detection watches a stream of unlabeled feature vectors and asks whether a classifier can tell recent data from a reference sample. These are real runs of the eadd package on five synthetic streams (6,000 samples, 5 features, drift in f0 and f1 from sample 3,000).

1 · WindowsReservoir-sampled reference (500) vs sliding current window (200)
2 · Classifier testLightGBM, 5-fold CV AUC every 50 samples
3 · ConfirmAUC > 0.7 triggers an adaptive sequential permutation test (α = 0.05)
4 · ExplainTreeSHAP ranks the features behind the drift, then the reference resets

Each chart shows one run with seed 42; numbers vary a little with the seed. On the recurring stream EADD confirms the first change. The thesis benchmark on 13 real-world streams and seven baseline detectors lives in the experiments repository.
